Intramurals Ranking System

Real-time medal tally board built with Firebase for Manolo Fortich National High School Intramurals.

Developed By

NanoNova Robotics Club – Programming Division

Purpose

Provide transparent, fast, and accessible live medal standings across events.

Key Capabilities

  • Live medal standings and point totals
  • Smooth ranking reorder animations
  • Admin total editor & mobile quick scorer
